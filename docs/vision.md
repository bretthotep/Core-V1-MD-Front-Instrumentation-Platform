# Vision — proposed

**Connect what you already have. Register it. Understand it. Connect it. Monitor it. Query it.**

The Secure Application Integration & Observability Fabric surrounds authoritative
customer systems. It makes business capabilities discoverable and safely consumable,
including systems with no API. It does not replace their applications or become a
new system of record.

The Application Twin provides progressively discovered context. Approved, narrowly
scoped capabilities expose that context through standard interfaces. An outbound
Connector Agent executes deterministic operations within the customer's security
boundary. Evidence-backed business health explains whether those capabilities still work.

The experience is an estate map rather than a CRM, spreadsheet, ESB designer, or
developer-only gateway. Users register a resource, review discoveries, connect
applications, approve mappings and security, deploy, and monitor changes.

Success means a customer can connect an existing Excel/VBA application to an approved
target, diagnose a broken dependency, and inspect returned data's provenance without
replacing the workbook or giving the cloud unrestricted machine access.

This is a proposed new product direction, not the purpose of the existing
Core V1-MD front-panel runtime. See [architecture](architecture.md) for repository findings
and [roadmap](roadmap.md) for approval gates.
